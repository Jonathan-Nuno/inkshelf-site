Inkshelf: Privacy Policy

Last updated: 16 October 2026

Inkshelf does not collect, store, transmit or share any personal data. The app has no accounts, analytics, advertising or tracking, and it makes no network connections.

Comics you import, your reading progress and your settings stay on your device, in the app's own storage, and are removed when you delete the app.

If you contact us for support, we use your message only to reply. Support requests are made as issues on GitHub Issues (github.com/Jonathan-Nuno/inkshelf-site/issues). Issues on GitHub are public and are handled by GitHub under its own terms and privacy statement, so please do not post personal information in an issue.

This website

This website is plain pages on GitHub Pages. It sets no cookies and runs no scripts or analytics. As the host, GitHub may process visitors' IP addresses in its server logs under its own privacy statement.

Contact

Open an issue on GitHub Issues. The support page is index.html.

Inkshelf is an independent app.
